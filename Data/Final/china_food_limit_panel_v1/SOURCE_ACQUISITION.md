# Source acquisition and exact-input verification

The Chinese source standards are not redistributed in this release. `source_manifest.csv` is the authoritative inventory of the 25 exact byte streams used, retained for identity audit, or archived without extraction. Each input is identified by a stable `source_id`, basename, byte length, and SHA-256 digest.

## How to use this guide

1. Follow the public locator for the relevant `source_id`.
2. Treat the downloaded filename as a hint. Compare its byte length and SHA-256 digest with `source_manifest.csv`.
3. Use a candidate only when its SHA-256 digest exactly matches. A current official or government-hosted file with a different digest is a reference copy and must not silently replace the frozen input.
4. If no byte-exact public download is recorded, cite the stable standard identity and request the frozen source bytes from the authors, subject to the source publisher's redistribution terms.

A blank `retrieved_date` in `source_manifest.csv` means that the original retrieval date was unrecorded. Public locators were checked on 2026-07-16. A locator found later establishes locatability at the check date and does not reconstruct original acquisition provenance.

Locator status meanings:

- `byte_exact_official_file`: the current issuing-authority file matched the frozen SHA-256 digest on the locator check date.
- `recorded_acquisition_url`: the URL was retained with the source record; the original retrieval date remains unrecorded.
- `standard_identity_only` and `page_images_identity_only`: the official page identifies the instrument, while the exact frozen-byte acquisition path remains unrecorded.
- `official_reference_copy_differs` and `government_reference_copy_differs`: the public reference file has a different byte identity.
- `authoritative_archive_identity_only`: an authoritative archive supplies a reference copy when no current issuer-hosted exact file was located.
- `related_standard_only`: the locator identifies the related standard; it does not identify the separate audit-copy byte stream.

Source classes (`source_class` in `source_manifest.csv`):

- `issuing_authority_file`: an edition text issued by the standard-setting authority. The locator status states whether the frozen bytes match a current issuer download.
- `government_hosted_copy`: a copy downloaded from a government website other than the issuing authority; it supplied released values.
- `third_party_translation`: an unofficial English translation used only for English labels.
- `audit_only_copy`: a file used for edition identity, OCR cross-checking or identity audit; no released value is read from it.
